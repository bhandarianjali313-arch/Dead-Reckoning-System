🔄 EKF / UKF / IEKF Sensor-Fusion & The 6 Unique Features

"When GNSS is available, it quietly helps maintain accurate positioning. When GNSS disappears, the system automatically switches to AI + IMU based dead reckoning, corrected using map matching and vehicle-motion constraints."

Stage 1: Collection

Raw Smartphone Sensors

Accel, Gyro, Mag, GNSS, and Camera Optical Flow.

Stage 2: Preprocessing

Virtual Alignment

Cleans sensor data & discovers orientation inside vehicle.

Stage 3: AI Inference

Motion Characterization

DeepIMUNet classifies speed, bumps, vibration, & reliability.

Stage 4: Positioning

ES-IEKF + Map Match

Seamless dead reckoning, NHC constraints & road snapping.

Unique Feature 1

1. Dynamic Process-Noise Adaptation

Instead of keeping uncertainty fixed, AI changes it according to driving situation.

• Smooth road → lower uncertainty (Q ~ 0.35x)
• Bumpy road or sharp turn → higher uncertainty (Q ~ 5.5x)
Unique Feature 2

2. Stop-Based Drift Correction

When the vehicle stops at red lights, the system estimates accumulated drift by comparing journey with road map.

• Generalized Likelihood Ratio standstill test (ZUPT)
• Corrects previous A → B trajectory before continuing to C
Unique Feature 3

3. AI Fallback Mechanism

We don't blindly trust AI. Safeguarded with instant physics failover.

• Abnormal sensor data or sudden phone movement detected
• Temporarily falls back to traditional IEKF, keeping navigation alive
Unique Feature 4

4. Seamless GNSS Switching

Dual-mode cooperation between GNSS and Dead Reckoning.

• When GNSS disappears → automatically relies on IMU + AI + Map
• When GNSS returns → smoothly corrects error instead of sudden jumping
Unique Feature 5

5. Confidence-Aware Navigation

Provides real-time indication of how confident it is and how much error exists.

• Real-time 2D covariance eigen-decomposition
• Extracts 95% horizontal confidence error ellipses (± meters)
Unique Feature 6

6. Optional Camera Assistance

Monocular visual odometry assisting inertial dead reckoning.

• Smartphone camera provides movement estimate using optical flow
• Works alongside IMU to bound longitudinal velocity drift
