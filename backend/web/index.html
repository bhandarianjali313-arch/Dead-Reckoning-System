⭐ Our 6 Unique Features
FEATURE 1 Active (Q: 0.35x)
Dynamic Process-Noise Adaptation
Instead of keeping uncertainty fixed, AI changes it according to the driving situation based on IMU spectral roughness and dynamics.
Impact: Smooth road → lower uncertainty ($Q \sim 0.35$); bumpy road or sharp turn → higher uncertainty ($Q \sim 5.5$).
FEATURE 2 Standby (Cruising)
Stop-Based Drift Correction
When the vehicle stops, the system gets an opportunity to estimate the accumulated drift by comparing the estimated journey with the road map.
Impact: Corrects previous $A \rightarrow B$ trajectory before vehicle continues toward $C$.
FEATURE 3 Dual Tripwire: Nominal
AI Fallback Mechanism
We don't blindly trust AI. If the AI becomes uncertain because of abnormal sensor data or sudden phone movement, the system safely intervenes.
Impact: Temporarily falls back to traditional robust physics-based Invariant EKF, keeping navigation alive.
FEATURE 4 Seamless Damping
Seamless GNSS Switching
GNSS and dead reckoning work together when GNSS is available. When GNSS disappears, the system automatically relies more on IMU, AI and map positioning.
Impact: Smoothly dampens innovation error upon exit instead of suddenly jumping.
FEATURE 5 95% Ellipse Bound
Confidence-Aware Navigation
The system provides not only a position but also an indication of how confident it is in that position and how much error may exist.
Impact: Provides drivers with real-time horizontal uncertainty radii ($\pm 1.2\text{m}$).
FEATURE 6 Visual Odometry Ready
Optional Camera Assistance
If needed, the smartphone camera can provide an additional movement estimate using visual information alongside IMU data.
Impact: Bounds velocity drift during prolonged tunnel blackouts.
